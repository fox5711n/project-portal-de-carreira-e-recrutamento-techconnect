# project-portal-de-carreira-e-recrutamento-techconnect
rojeto acadêmico desenvolvido para a disciplina de **Desenvolvimento Web** do curso de **Análise e Desenvolvimento de Sistemas (ADS)**, com foco na construção de um **portal de carreiras e recrutamento**, aplicando conceitos fundamentais e práticos de desenvolvimento web.

O sistema simula uma plataforma onde usuários podem visualizar oportunidades, interagir com formulários e navegar por diferentes seções de forma organizada e intuitiva.

---

## 🎯 Objetivo do Projeto

O objetivo deste projeto foi aplicar, na prática, os conhecimentos adquiridos em sala de aula, abrangendo:

- Estruturação de páginas web com HTML semântico  
- Estilização e organização visual com CSS  
- Interatividade e validações no front-end com JavaScript  
- Processamento de dados e lógica de negócio no back-end com PHP  
- Integração entre páginas sem recarregar a aplicação em novas abas  

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** – Estruturação semântica das páginas  
- **CSS3** – Estilização, layout e organização visual  
- **JavaScript** – Interatividade, validações e experiência do usuário  
- **PHP** – Processamento de formulários, lógica de negócio e integração entre páginas  
- **Git & GitHub** – Versionamento e publicação do projeto  

---

## ⚙️ Funcionalidades Implementadas

- Navegação entre páginas de forma fluida  
- Formulários com validação no front-end e no back-end  
- Processamento de dados via PHP  
- Estrutura organizada de arquivos e pastas  
- Separação clara entre camadas de apresentação e lógica
